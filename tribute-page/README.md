# tribute-page
Kabza De Small Tribute Page
Description

A highly visual tribute website for Kabza De Small, a South African music producer known for his contribution to the emergence of amapiano music genre.

Features
Page title and one-line tagline
Prominent artist image
Biography section with four paragraphs
Musical journey timeline
Styled tribute quote
Multiple background colours
Typography – Serif & Sans-serif
Responsive Design For Desktop And Mobile
Technologies Used
HTML5
CSS3

How to Run

Explore the tribute page.
