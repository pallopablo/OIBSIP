# Calculator Project

## Description

An all-in-one calculator with full functionality developed with HTML5, CSS3, and JavaScript.

## Features

* Display screen showing current input and result
* Numeric buttons (0–9)
* Decimal point
* Addition, subtraction, multiplication, and division
* Equals button
* Clear button
* Backspace/Delete button
* Division-by-zero error handling
* Operator chaining
* CSS Grid layout
* JavaScript event listeners
* No `eval()` function used

## Tech Stack used

* HTML5
* CSS3
* JavaScript (Vanilla)

## How to Run

1. Clone/download this repo.
2. Open `index.html` in your browser.
3. Click on the calculator button to do arithmetic calculations.
